Admin

Admin är avstängt

Sätt ADMIN_PASSWORD i .env och starta om containern för att använda admin-sidan.

ADMIN_PASSWORD=ett-långt-lösenord
docker compose up -d

Logga in

Inställningarna gäller alla kameror och sparas i appens databas. Värdena från .env används som standard tills du ändrar dem här. Ändringar gäller direkt, utan omstart.
